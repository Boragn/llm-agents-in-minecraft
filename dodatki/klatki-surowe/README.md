# Surowe klatki ASCII

[artykuł](../../README.pl.md) · [article (EN)](../../README.md) · [dodatki](../README.md)

Pełne pliki tekstowe, które model albo prototyp widział w danej chwili. Bez zmian, poza nazwą pliku.

| plik | co to jest |
|---|---|
| [wy8-001-kupiec.txt](wy8-001-kupiec.txt) | klatka środowiska Borysa, WY-8 tura 1 (w domku) |
| [wy8-011-kupiec.txt](wy8-011-kupiec.txt) | klatka środowiska Borysa, WY-8 tura 11 (`eksploruj las`) |
| [wy8-014-lucznik.txt](wy8-014-lucznik.txt) | klatka środowiska Wilgi, WY-8 tura 14 (po sprzedaży) |
| `projekcja-<miejsce>-klatka.txt` | obecna klatka v1 z prototypu (pełna wiedza o świecie) |
| `projekcja-<miejsce>-p1.txt` | przejezdność 2,5D |
| `projekcja-<miejsce>-p2.txt` | radar kątowy z listą afordancji |
| `projekcja-<miejsce>-p4.txt` | kombinacja w zmiennej rozdzielczości |

Miejsca: `domek-wnetrze` i `mur-horda` (figura z czterema rzutami w artykule, sekcja 2). Pliki projekcji są wejściami [testu percepcji](../test-percepcji/wyniki.md): warianty klatka, p1, p2 i p4 dla obu scen.
